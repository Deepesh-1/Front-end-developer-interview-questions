The Next.js interview questions I'd prepare
Given you're targeting Lead React / Technical Architect roles, I'd prepare these in this order:

**Fundamentals**
1. What is Next.js?
2. Why Next.js over React/Vite?
3. App Router vs Pages Router?
4. What is file-based routing?
5. What are layouts?
6. Dynamic routes?
7. Route groups?
8. Nested layouts?
   
**Rendering**
10. CSR vs SSR?
11. SSG vs SSR?
12. ISR?
13. Dynamic rendering?
14. Streaming?
15. Hydration?
16. Server Components vs Client Components?
17. When should you use 'use client'?
18. Can Server Components contain Client Components?
19. Can Client Components import Server Components?

**Data**
20. How do you fetch data in Next.js?
21. How does caching work?
22. What is revalidation?
23. How do you invalidate/revalidate data?
24. How do you avoid request waterfalls?
25. Server Actions vs Route Handlers?

**Performance**
26. How do you optimize Next.js performance?
27. How does Next/Image work?
28. How do you optimize fonts?
29. Code splitting?
30. Dynamic imports?
31. Streaming/Suspense?
32. How do you reduce client JavaScript?
33. How would you debug a slow Next.js application?

**Security**
34. Authentication?
35. JWT vs session?
36. How do you store JWT?
37. Middleware/Proxy authentication?
38. Authorization/RBAC?
39. Server Actions security?
40. CSRF?
41. XSS?
42. Environment variables?
43. How do you protect API routes?

**SEO**
44. How do you implement SEO?
45. Metadata API?
46. Dynamic metadata?
47. Sitemap?
48. Robots?
49. Structured data?
50. Why SSR/SSG helps SEO?

**Architecture**
51. How would you structure a large Next.js application?
52. Where do you put API calls?
53. How do you organize components?
54. How do you separate Server/Client Components?
55. How would you implement authentication?
56. How would you implement RBAC?
57. How would you design an e-commerce application?
58. How would you handle micro-frontends with Next.js?
59. How would you integrate GraphQL?
60. How would you handle state management?
61. How would you deploy and scale it?
